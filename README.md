# Talha Ali - Portfolio

Personal portfolio for Talha Ali, Forward Deployed Engineer | AI Integration Engineer, based in Karachi, Pakistan.

Built with Next.js, [shadcn/ui](https://ui.shadcn.com/), and [magic ui](https://magicui.design/), deployed on Vercel. Based on the Magic UI portfolio template by Dillion Verma.

# Update it

All personal content lives in the single config file: [src/data/resume.tsx](./src/data/resume.tsx)

# Getting Started Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/talhaali-dev/Talha-portfolio
   cd Talha-portfolio
   ```

2. Install dependencies:

   ```bash
   pnpm install
   ```

3. Start the local server:

   ```bash
   pnpm dev
   ```

# Notes

- The avatar is Talha's GitHub avatar. Work and project logos are intentionally blank (placeholder circles) until real logos are added.
- Education and hackathons are intentionally empty in `src/data/resume.tsx` rather than filled with invented dates or events. Add them there when ready.
- The original template's blog posts were not carried over. Add your own posts under `content/` to populate the blog.
